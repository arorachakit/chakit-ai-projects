# RAG Chat — chakit.ai

Chat that grounds answers in your documents. Upload PDFs or images, ask anything, get cited responses. Re-skinned with the chakit.ai Cupertino design system.

## Develop

```bash
pnpm install
pnpm --filter ragapp dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit the page at `app/page.tsx`; styles live in `app/globals.css` (Cupertino tokens) and `tailwind.config.js` (chakit preset).
